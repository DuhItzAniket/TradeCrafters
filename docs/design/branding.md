# TradeCrafters mark

The project logo is [the square PNG](../../apps/web/public/brand/tradecrafters-mark.png), for the local GitHub OAuth app avatar. Generated with the built-in image-generation tool on 20 October 2026, then saved into the repository. It uses an intertwined TC lettermark in warm amber on graphite.

Generation prompt:

> Use case: logo-brand. Create one polished, original logo icon for TradeCrafters, a global stock-market learning and paper-trading application. Asset: square OAuth application avatar, a single finished mark, no presentation sheet. Design a very simple, distinctive geometric interlocked TC monogram, strong compact silhouette with thoughtful negative space, balanced slightly architectural letter construction, clear at 32 pixels. Warm muted amber #EDBC6B symbol on a perfectly flat solid graphite #191C1F square background. Center the icon with generous even margin; monogram occupies about 64 percent of square. Crisp flat vector-like edges, restrained premium financial-editorial identity. No words or tagline; only the integrated TC lettermark. No charts, candles, arrows, coins, bulls, globes, gradients, shadows, glow, texture, bevels, perspective, mockups, frames or watermarks. Deliver a single square high-resolution logo icon suitable for uploading directly to GitHub OAuth app settings.

The original generated PNG is retained without raster edits. The existing editable small app icon remains available separately.
